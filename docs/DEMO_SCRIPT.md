# Five-minute demonstration

1. Open the dashboard and explain the control posture on the right.
2. Run the prefilled high-value payment-timeout scenario.
3. Show the `waiting_approval` state and that zero tools have executed.
4. Expand the evidence cards and point out tenant-aware `knowledge://` citations.
5. Approve as the independent checker.
6. Show the journal moving through execution and verification to completion.
7. Open `/docs` to demonstrate the API and tool catalog.
8. Open Jaeger and show spans for retrieval, planning and tool execution without prompt content.
9. Run the same idempotency key through the API and show that no duplicate workflow is created.
10. Finish with the threat model and the explicit production gaps.

The key message: models help interpret work, but policy, identity, approval, execution and verification
stay within deterministic enterprise controls.
